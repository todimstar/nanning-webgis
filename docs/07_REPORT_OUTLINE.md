# 07 课设报告大纲

## 1. 项目概述

项目名称：

> 基于 OpenLayers 的南宁城市健康宜居环境评估 WebGIS 系统

项目背景：

- 敏感体质人群和青年租住群体在选择居住地点时，需要关注空气、湿度、噪音、医疗、绿地等因素。
- 传统地图更偏重导航和 POI 查询，缺少面向个人健康偏好的环境适宜性分析。
- 本项目通过 WebGIS 与 AI 规则模型，将城市微环境数据转化为可解释的居住建议。

## 2. 需求分析

用户画像：

- 呼吸道敏感
- 皮肤敏感
- 睡眠浅怕吵
- 普通宜居

核心需求：

- 地图查看
- 环境查询
- 综合评分
- 推荐解释
- 空间分析
- 热力展示
- 结果导出

## 5. 评分模型

介绍指标：

- 空气质量
- 湿度舒适度
- 紫外线安全
- 噪音舒适度
- 绿地便利
- 医疗便利
- 生活便利

介绍公式：

```text
综合评分 = Σ 指标分 × 用户画像权重
```

## 6. 创新点

1. 面向敏感体质人群的个人化居住建议。
2. 从“地图查询”扩展为“城市微环境决策支持”。
3. 夜间噪音风险模型，不依赖真实噪音传感器。
4. 规则式 AI 解释，让评分结果可理解。
5. 适合后续扩展至租房避雷、大学生选址、背包客短住推荐。

## 8. 测试与演示

演示流程：

1. 打开系统。
2. 切换底图。
3. 开关环境图层。
4. 选择“皮肤敏感”画像。
5. 点击南宁某区域。
6. 查看评分和解释。
7. 绘制候选范围。
8. 进行空间查询。
9. 查看热力图。
10. 导出截图。
