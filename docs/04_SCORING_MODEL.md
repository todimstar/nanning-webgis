# 04 综合评分模型

## 一、用户画像

系统内置 4 种画像：

1. respiratory：呼吸道敏感
2. skin：皮肤敏感
3. sleep：睡眠浅怕吵
4. general：普通宜居

用户选择不同画像后，系统使用不同权重计算综合适宜度。

## 二、指标

所有指标归一化为 0-100，越高越适宜。

### airQuality

空气质量分。

可参考：

- PM2.5 越低越好
- PM10 越低越好
- AQI 越低越好
- O3、NO2 作为辅助

简化实现：

```text
airQuality = 100 - AQI
```

若 AQI 不存在：

```text
airQuality = 100 - PM2.5 * 2
```

并限制在 0-100。

### humidityComfort

湿度舒适分。

简化规则：

```text
湿度 40%-60%：100
湿度 30%-40% 或 60%-70%：80
湿度 20%-30% 或 70%-80%：60
湿度 <20% 或 >80%：40
```

皮肤敏感模式下，湿度过高要明显扣分。

### uvSafety

紫外线安全分。

```text
UV <= 2：100
UV 3-5：80
UV 6-7：60
UV 8-10：40
UV > 10：20
```

### noiseComfort

噪音舒适分。

```text
noiseComfort = 100 - noiseRisk
```

noiseRisk 由噪音风险模型计算。

### greenSpace

绿地便利分。

根据最近公园/绿地距离：

```text
<= 300m：100
<= 800m：80
<= 1500m：60
<= 3000m：40
> 3000m：20
```

### medical

医疗便利分。

根据最近医院/诊所/药店距离：

```text
<= 300m：100
<= 800m：80
<= 1500m：60
<= 3000m：40
> 3000m：20
```

### lifeConvenience

生活便利分。

根据餐饮、超市、便利店、商场等 POI 数量：

```text
500m 内 >= 15 个：100
500m 内 >= 8 个：80
500m 内 >= 3 个：60
500m 内 >= 1 个：40
0 个：20
```

### roadDistance

道路安静分。

离主干道越远越好：

```text
>= 800m：100
500-800m：80
300-500m：60
100-300m：40
< 100m：20
```

### nightPoiDensity

夜间 POI 安静分。

酒吧、餐饮、影院等夜间活跃 POI 越少越好：

```text
500m 内 0-1 个：100
2-4 个：80
5-8 个：60
9-15 个：40
>15 个：20
```

## 三、综合评分

```text
score = Σ metricScore * profileWeight
```

配置来自：

```text
public/data/score-config.json
```

## 四、等级划分

```text
>= 85：非常推荐
70-84：推荐
55-69：一般
40-54：谨慎
< 40：不推荐
```

## 五、解释模板

系统应输出 3 类内容：

1. 总结
2. 优势
3. 风险
4. 建议

示例：

```text
该位置对“皮肤敏感”用户的适宜度为 76 分，属于推荐区域。
优势：空气质量较好，周边医疗设施较近，紫外线风险处于中等水平。
风险：当前湿度偏高，夏季可能出现闷热潮湿感；距离主干道较近，夜间可能存在一定噪音。
建议：可以作为候选区域，但建议优先选择不临街、通风较好的楼栋。
```
