# 06 验收清单

## 一、运行验收

- [ ] `npm install` 成功。
- [ ] `npm run dev` 成功。
- [ ] `npm run build` 成功。
- [ ] 页面无明显控制台报错。
- [ ] 即使 Open-Meteo 请求失败，页面也不会崩溃。
- [ ] 即使 nanning_poi.geojson 缺失，页面也有 demo 数据可演示。

## 二、地图基础功能

- [ ] 地图默认定位到南宁。
- [ ] 至少有 3 种底图。
- [ ] 可以切换底图。
- [ ] 有缩放控件。
- [ ] 有全屏控件。
- [ ] 有复位按钮。
- [ ] 有比例尺。
- [ ] 有鼠标坐标显示。
- [ ] 有鹰眼图。

## 三、图层功能

- [ ] 可以显示/隐藏 POI 图层。
- [ ] 可以显示/隐藏道路图层。
- [ ] 可以显示/隐藏热力图。
- [ ] 可以调节图层透明度。
- [ ] 图层开关状态和地图显示一致。

## 四、环境评估功能

- [ ] 点击地图可以获取当前点坐标。
- [ ] 点击地图可以调用天气 API。
- [ ] 点击地图可以调用空气质量 API。
- [ ] 右侧显示温度。
- [ ] 右侧显示湿度。
- [ ] 右侧显示风速。
- [ ] 右侧显示 PM2.5。
- [ ] 右侧显示 PM10。
- [ ] 右侧显示 AQI。
- [ ] 右侧显示 UV。
- [ ] 可以切换用户画像。
- [ ] 不同画像评分会变化。
- [ ] 输出综合评分。
- [ ] 输出自然语言解释。

## 五、噪音风险模型

- [ ] 根据道路距离估算噪音风险。
- [ ] 根据夜间 POI 密度估算噪音风险。
- [ ] 输出 noiseRisk。
- [ ] 输出 noiseComfort。
- [ ] 能在解释中说明噪音风险来源。

## 六、WebGIS 交互工具

- [ ] 支持点绘制。
- [ ] 支持线绘制。
- [ ] 支持面绘制。
- [ ] 支持圆绘制。
- [ ] 支持矩形绘制。
- [ ] 支持编辑绘制要素。
- [ ] 支持删除绘制要素。
- [ ] 支持距离测量。
- [ ] 支持面积测量。

## 七、查询与分析

- [ ] 支持点选查询。
- [ ] 支持框选查询。
- [ ] 支持圆选查询。
- [ ] 支持属性筛选。
- [ ] 支持缓冲区分析。
- [ ] 支持 POI 密度统计。
- [ ] 支持热力图展示。
- [ ] 支持未来 24 小时趋势图。

## 八、导出与展示

- [ ] 支持地图截图。
- [ ] 支持导出当前评估结果。
- [ ] README 说明清楚。
- [ ] 项目适合 3-5 分钟演示。
- [ ] 可以部署到 GitHub Pages。
