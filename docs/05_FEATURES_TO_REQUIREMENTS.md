# 05 课程要求与项目功能对应表

## 基础功能

| 课程要求 | 本项目实现 |
|---|---|
| 多源地图加载 | OSM、卫星/影像、深色/地形底图 |
| 基本地图控制 | 缩放、平移、复位、全屏 |
| 图层管理 | 环境图层、POI 图层、道路图层、热力图、综合评分图层 |
| 比例尺 | OpenLayers ScaleLine |
| 鼠标坐标 | PointerMove 显示经纬度 |
| 鹰眼 | OverviewMap 控件 |

## 交互功能

| 课程要求 | 本项目实现 |
|---|---|
| 点绘制 | 添加候选居住点 |
| 线绘制 | 标记通勤路线 |
| 面/圆/矩形绘制 | 圈选候选居住范围 |
| 要素编辑与删除 | 编辑/删除候选点和自定义区域 |
| 距离测量 | 测量到学校、医院、公园、主干道距离 |
| 面积测量 | 计算圈选区域面积 |
| 地图标注与信息弹窗 | 点击点位显示环境指标和评分解释 |
| 地图截图/导出 | 导出当前评估地图 |

## 高级功能

| 课程要求 | 本项目实现 |
|---|---|
| 空间查询 | 点选、框选、圆选查询 POI 和候选点 |
| 属性查询 | 按 AQI、PM2.5、噪音风险、综合评分筛选 |
| 空间分析 | 主干道/夜间 POI 缓冲区噪音风险分析 |
| 叠加分析 | 环境指标 + POI + 道路风险叠加评分 |
| 热力图 | 综合评分热力图、噪音风险热力图 |
| 轨迹回放/动态数据 | 未来 24 小时空气质量/湿度趋势图，或模拟一天内指标变化 |

## 扩展功能

| 课程要求 | 本项目实现 |
|---|---|
| 地理编码/逆地理编码 | 可选，高德/天地图/Nominatim |
| 路径规划 | 选做，不作为第一版核心 |
| 时空数据可视化 | 未来 24 小时趋势图 |
