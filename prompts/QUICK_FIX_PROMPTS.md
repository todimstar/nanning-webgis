# 常用追问 Prompt

## 1. 地图跑不起来

```text
现在项目地图无法正常显示，请你检查 OpenLayers 初始化、CSS 容器高度、底图 source、投影坐标转换和控制台报错。请修复后确保 npm run dev 可以正常显示南宁地图。
```

## 2. Open-Meteo 请求失败

```text
Open-Meteo 请求失败，请你检查 API URL 拼接、经纬度顺序、CORS、current/hourly 字段解析，以及错误降级逻辑。要求 API 失败时页面不崩溃，并提示用户当前使用示例数据。
```

## 3. Overpass 数据太大或抓取失败

```text
Overpass 数据抓取失败或太大，请你缩小南宁 bbox 到主城区，并给 fetch-overpass-nanning.mjs 增加分类抓取、重试、错误提示和输出 demo 数据的降级逻辑。
```

## 4. 课程功能不完整

```text
请根据 docs/06_ACCEPTANCE_CHECKLIST.md 检查当前项目还缺哪些 WebGIS 课程功能，并按优先级补齐：图层管理、绘制、编辑、删除、测距、测面积、空间查询、属性查询、缓冲区分析、热力图、截图导出、动态趋势图。
```

## 5. UI 太丑

```text
请优化 UI，但不要破坏功能。要求三栏布局清晰，左侧工具栏、中间地图、右侧分析面板；适配 1366px 桌面屏和移动端；使用卡片、标签、评分仪表或进度条展示环境指标。
```

## 6. 解释太像模板

```text
请优化 explainModel.js 的规则式 AI 解释，让它根据具体指标动态生成更自然的推荐理由、风险提醒和居住建议。不要调用真实 LLM。
```

## 7. 准备课设演示

```text
请帮我为当前项目生成 3-5 分钟演示流程、README 项目说明、课设报告功能说明和创新点说明。重点突出 OpenLayers 综合应用、健康宜居评分、噪音风险模型和规则式 AI 解释。
```
